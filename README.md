## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies `POST.json` (the X post's address) to the output directory. The meme itself is `meme.png`: a neon Vice City street at dusk, the official make.fun ghost on a billboard, and the 13-year wait as the joke.
